# Website rules

- Keep interactions direct and language simple.
- Do not use emojis or Unicode characters as icons anywhere on the website. This includes buttons, menus, status messages and public content from Google Forms or Sheets.
- Use Lucide SVG icons or the existing `assets/icons/hilth-symbols.svg` sprite. Hide decorative icons from assistive technology and label icon-only controls.
- Follow `DESIGN.md` and run `python scripts/check-site.py` before committing website changes.
